Règles de travail à deux

  • Une branche git par personne, on fusionne aux deux moments ensemble (samedi 18h, dimanche 13h).
  • On respecte le contrat API. Si on doit le changer, on prévient l'autre avant.
  • Bloqué plus de 30 min ? On demande de l'aide tout de suite.
  • Chaque source utilisée va dans SOURCES.md au moment où on l'utilise.

Si on manque de temps, on coupe dans cet ordre

  1. Assistant RAG → amélioration future
  2. Prédiction os / radiation → amélioration future
  3. Animations du jumeau numérique → couleurs fixes
  4. Déploiement en ligne → la vidéo suffit

On ne coupe jamais : PVT, détection d'anomalies, alertes avec actions, vidéo.
